# Products Page Overrides

> Rules in this file **override** `design-system/aisikai/MASTER.md`.
> Only deviations from the Master are documented here. For all other rules, refer to the Master.

## Deviations

### Equal product cards

Each card has the same image frame, then the product name, then the category in muted slate (`#475569` on light). Hover changes the border or background and does not shift the layout.

### Sidebar

Category navigation is a sidebar beside the product grid. The active category uses the accent. The panel is in the page column, not an uncontained absolute layer.

### Spec labels in Open Sans

STANDARDS and FEATURES use Open Sans, small size, medium weight, and letter-spacing. No Playfair, italic, or underline.
